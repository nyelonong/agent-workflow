Write a social media post for ${1:-X} about ${@:2}.

Use this voice:
- Casual maker voice with a small technical wink.
- First-person, direct, relaxed, curious, and quietly confident.
- Short sentences and concrete verbs.
- Technical enough to be specific, but never formal or corporate.
- The feeling is: “I made a weird useful thing, and you can try it.”
- Use personal experiment + concrete behavior + small wink as the default structure.
- Keep the language natural and conversational. Do not sound like launch copy.
- Prefer a light insider reference when it fits, but never force a Linux meme or joke.

Avoid:
- Startup and marketing clichés: revolutionary, seamless, supercharge, game-changing, unleash.
- Corporate engineering-announcement tone.
- Overly poetic creative-coding language.
- Invented metrics, testimonials, or claims.
- Excessive emojis, hashtags, and exclamation marks.
- Explaining the joke.

Platform guidance:
- X: concise, conversational, readable as a single post or short thread.
- Threads: slightly looser and more personal than X.
- LinkedIn: still human, but include one concrete engineering detail.
- Instagram: write a caption with a strong first line and a clear visual suggestion.
- TikTok: write a spoken hook, short voiceover, and on-screen caption.

Return only the finished post unless a format choice is genuinely unclear. Match the user's requested language. If no language is specified, use English.
