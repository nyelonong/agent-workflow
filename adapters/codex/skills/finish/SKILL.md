# Finish

Apply the shared workflow's integrated-finish contract to the complete result against the approved outcome and technical plan. Review interactions; per-task evidence alone does not prove composition. Reuse applicable review coverage rather than loading review or launching another reviewer merely because finishing began. Required review must precede its applicable delivery/safety boundary.

Establish the repository's documented full gate against this result. Reuse a current result already proving it; run missing or invalidated checks and preserve stricter repository requirements. With no documented gate, use appropriate supported typecheck, lint and full-suite checks. Resolve blocking findings through the same closeout; do not restart task verification.

After integrated acceptance and sufficient gate evidence, record actual results and set the plan's next action to the user's final decision. Recommend merge, pull request, keep or discard with the evidence, limits and residual risks. A passing gate authorizes no unreviewed commit, remote write or destructive cleanup. Perform only the exact action the user explicitly authorizes; preserve unintegrated work.
