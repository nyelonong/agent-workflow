# Verify

Name the claim and scope. Apply the shared workflow's evidence-reuse contract: use applicable proof after the last relevant edit; run the narrowest missing or invalidated check. Preserve repository requirements, including a per-task gate when required. Integrated claims need interaction coverage and the full gate, not only task checks.

Confirm proof exercises the changed behavior at a meaningful boundary; unrelated passing suites, milestones, coverage numbers and agent reports are insufficient. For material or uncertain changes record the changed path, load-bearing safety facts, strongest applicable evidence and unproved risks. Report commands/results, skips, counts where applicable and evidence limits once in the closeout packet.

When automation cannot prove a user-visible claim, use an authorized concrete manual check and record observations. Do not infer success from a planned step.

Verification does not authorize production edits. Route an unknown failure to investigate and a known in-scope correction to implementation, then reassess affected proof. In a broader active task continue closeout without a phase-only stop or duplicate report. For a standalone request return the verdict and evidence.
