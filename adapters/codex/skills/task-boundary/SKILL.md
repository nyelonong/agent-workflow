---
name: task-boundary
description: Reset the agent's task state after a requirement, scope, or branch change
---
Before continuing, restate the current task using this structure:

- Goal
- Acceptance criteria
- Non-goals
- Allowed repositories and files
- Target branch
- Required verification
- Prior assumptions or work that no longer apply

Use the user's new context. Do not modify files or run mutating commands. Ask one plain numbered question requesting approval or correction, recommend the proposed scope with its reason, and stop until answered. Silence or cancellation does not authorize work.
